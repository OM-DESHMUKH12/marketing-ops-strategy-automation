# Gemini Coding Instructions

1. Read `AGENTS.md` and `PROJECT_STATUS.md` before editing.
2. Read `NEXT_STEPS.md` and `HANDOFF.md`, then inspect the actual repository.
3. Reuse existing modules; avoid unnecessary rewrites.
4. Verify implementation and tests rather than inferring status from code presence.
5. Update handoff and project continuity documents after substantial changes.

`AGENTS.md` is the canonical, tool-independent development policy.
